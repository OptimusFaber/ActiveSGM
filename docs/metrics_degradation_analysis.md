# Анализ причин ухудшения метрик

## Найденные различия между оригинальной и текущей конфигурацией

### 🔴 Критические различия (могут влиять на метрики)

#### 1. **dataset_eval_basedir** ⚠️ КРИТИЧНО
- **Оригинал**: `"data/replica_sim_nvs"` (novel views - невиданные ракурсы)
- **Текущее**: `"data/Replica"` (те же кадры, что для обучения)

**Влияние**: 
- Валидация на `data/Replica` проверяет качество на уже виденных кадрах → завышенные метрики
- Валидация на `data/replica_sim_nvs` проверяет обобщающую способность → более реалистичные метрики
- **Рекомендация**: Используйте `data/replica_sim_nvs` для корректной оценки

#### 2. **semantic_device**
- **Оригинал**: `"cuda:1"` (отдельная GPU для семантики)
- **Текущее**: `"cuda:0"` (та же GPU, что для SLAM)

**Влияние**:
- При использовании одной GPU может быть нехватка памяти или конфликты
- **Рекомендация**: Если есть 2 GPU, используйте `cuda:1` для семантики

#### 3. **eval_during_training_freq**
- **Оригинал**: Не указано (валидация только в конце)
- **Текущее**: `200` (валидация каждые 200 шагов)

**Влияние**:
- Периодическая валидация может замедлять обучение
- Но помогает отслеживать прогресс
- **Рекомендация**: Можно оставить для мониторинга, но не критично

#### 4. **up_dir**
- **Оригинал**: `np.array([0, 0, 1])`
- **Текущее**: `[0, 0, 1]` (обычный список)

**Влияние**: Минимальное, но может влиять на вычисления планирования
- **Рекомендация**: Используйте `np.array([0, 0, 1])`

### 📋 Другие возможные причины ухудшения метрик

#### 1. **Различия в версиях зависимостей**
- PyTorch версия
- CUDA версия
- Версии других библиотек (Habitat, OneFormer и т.д.)

**Проверка**:
```bash
pip list > current_versions.txt
# Сравните с версиями из оригинального репозитория
```

#### 2. **Различия в данных**
- Версия датасета Replica
- Качество семантических меток (OneFormer fine-tuning)
- Различия в траекториях камеры

**Проверка**:
```bash
# Сравните количество кадров
ls data/Replica/office0/results_habitat/frame*.jpg | wc -l
ls ActiveSGM-Orig/data/Replica/office0/results_habitat/frame*.jpg | wc -l
```

#### 3. **Случайность (random seed)**
- Разные seed могут давать разные результаты
- Особенно влияет на активное планирование (выбор поз)

**Проверка**: Запустите несколько раз с разными seed и усредните метрики

#### 4. **Гиперпараметры обучения**
- Learning rates
- Количество итераций mapping
- Параметры pruning и densification

**Проверка**: Сравните `configs/Replica/replica_splatam_s.py` в обоих репозиториях

#### 5. **Окружение выполнения**
- GPU модель и драйверы
- Температура GPU (thermal throttling)
- Конкурирующие процессы
